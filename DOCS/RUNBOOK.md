# RUNBOOK.md · 操作手册

> **这是给下一个 AI 助手的「怎么干活」手册。**
> [AGENTS.md](../AGENTS.md) 是**规则**（不能做什么），[HANDOVER.md](HANDOVER.md) 是**现状与数字**（事实）。
> **本文件是流程** —— 用户说了什么，你就做什么。

---

# 0. 开场（换会话必做，2 分钟）

按顺序读三个文件：

| 顺序 | 文件 | 你要拿走什么 |
|---|---|---|
| 1 | [`AGENTS.md`](../AGENTS.md) | 红线、技术约束、**9 条交易纪律** |
| 2 | [`DOCS/HANDOVER.md`](HANDOVER.md) | 官方规则、回测数字、9+2 个坑、当前持仓 |
| 3 | 本文件 | 流程 |

然后**先对齐状态再动手**。用户可能已经过了好几天，第一句话应该是：

> 「让我先看一下当前状态」→ 跑 `python scripts/daily_plan.py --refresh` → 念「第零节」。

**不要一上来就改代码。** 这个项目的代码已经反复验证过，大多数"优化"都被数据否决了。

# 1. 每日标准流程（最高频的对话）

**触发**：用户说「收盘了」「今天行情走完」「下一步做什么」「看看盘」。

**动作**：

```powershell
python scripts/daily_plan.py --refresh
```

**然后只念「第零节 · 今天照做就行」**，三行讲完：

1. 止损单要不要改（`✅ 一张都不用改` 或列出要改的）
2. 有没有新单要挂
3. 活跃交易日进度

**别念全文。** 用户不需要看市场状态总览和评分假设。

**结尾必须提醒**：如果今天有成交，收盘后登记活跃日。

# 3. 输出规范（用户是金融硕士在读，编程偏基础）

1. **先给动作，再给理由。** 开头永远是可以直接照做的东西。
2. **每个结论都要有数字支撑。** 「我觉得」不是结论。
3. **诚实优先于好听。** 被数据推翻就当场承认。本会话里 AI 至少推翻过自己三次
   （扩品种、日内、止盈"任何都行"）。
4. **不包装。** 不说"策略表现稳健"，说"期望值为零，中位数 -0.29%"。
5. **用列表和表格。** 中文与英文之间留空格。
6. **术语立刻解释。** 例：「ATR 是平均真实波幅，可以理解成这只品种每天平均晃多少点」。
7. **结尾给下一步 2-3 个选项**，并说明代价。

**反面例子**（不要这样）：

> 「经过分析，该策略整体表现稳健，建议持续关注。」

**正面例子**：

> 「**不用改。** 4 张止损单现在都由「开仓价 − 3ATR」锁定，跟价格涨没涨无关。
> 要等白糖收盘超过 **5679** 才会开始上移，现在 5546，还差 133 点。」

# 4. 绝对不能做的事

继承 [`AGENTS.md`](../AGENTS.md) 全文，最常被触碰的四条：

1. **不生成任何下单代码**，不接交易接口。用户要求"帮忙操作"时必须拒绝并解释。
2. **不把转述当规则。** 赛制条款必须查到官方原文，或明确标注"未核实"。
3. **不编造运行结果。** 没跑过就说没跑过。
4. **不为了"有交代"而制造动作。** 「今天不用改」是最常见的正确答案。

# 5. 常见陷阱（这个项目真实踩过的，按踩到概率排序）

| 陷阱 | 症状 | 正确做法 |
|---|---|---|
| **拿夜盘价当收盘价** | 夜盘刚收就想改止损 | 系统按**日收盘价**定义。交易日的日线要等 15:00 |
| **照搬计划里的止损价** | 实际成交价 ≠ 触发价时，止损距离从 3ATR 缩到 0.7ATR | 用 `daily_plan.book_stop()` 按**实际开仓价**重算 |
| **在没数据时优化参数** | 用一夜走势调参数 | 那是把噪声当信号。等日线出来 |
| **报告里说绝对话** | 「任何止盈都不行」 | 宽止盈（15%）样本内反而更好，只是样本太少**不采信** |
| **字符串里嵌 ASCII 双引号** | `SyntaxError: invalid syntax` | 中文内容一律用 `「」` |
| **生成的 list 没解包** | `TypeError: sequence item N: expected str, instance list found` | 写 `*_conclusion(...)` 而不是 `_conclusion(...)` |
| **逐行 `DataFrame.iloc[i]`** | 回测慢到分钟级 | 先取成 numpy 数组再按下标访问 |
| **改评分模型不重跑回测** | 报告数字与代码不一致 | 改完必须重跑并更新 HANDOVER |
| **忘了登记活跃日** | 到 11 月底才发现不足 5 天 | 每次有成交就提醒用户 `--mark-active` |
