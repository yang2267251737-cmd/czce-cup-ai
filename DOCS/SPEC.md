# SPEC.md · 规格书

> 版本 v2.0　更新日期：2026-10-09
> 第一轮（数据探针）之后的完整规格。所有数字与结论都标注了来源或「未能核实」。

## 1. 一句话定位

**在「收益率 80% + 回撤 10% + 活跃度 10%」的加权赛制、手续费按交易所标准 1.5 倍收取、
且只能用官方软件手工下单的约束下，用可复现的历史统计求「最优交易节奏」，并把它变成
每个交易日一张照着就能挂单的操作清单。**

后半句才是重点：不是"我用 AI 炒股"，而是"我把一个多目标约束下的决策问题拆成了可验证的模块"。

## 2. 用户故事

我是这个系统唯一的用户，金融硕士在读，能读懂和修改代码但不擅长从零写程序，每周投入 5–8 小时。

- 作为参赛者，我希望每个交易日收盘后拿到**次日的操作清单**：挂什么价、几手、止损放哪。
- 作为参赛者，我希望知道**某个信号为什么没被采纳**，而不是只看到一个黑箱结论。
- 作为求职者，我希望仓库里有**回测报告、假设敏感性分析和决策日志**，
  让面试官能看出"哪些是 AI 做的、哪些是我判断的"。
- 作为时间有限的学生，我希望整套流程能在**一条命令内**跑完，并且断网也能跑。

## 3. 功能清单

### Must（必做，已完成）

| 模块 | 输入 | 输出 | 验收标准 |
|---|---|---|---|
| `contracts.py` 合约规格 | 无（联网或本地快照） | `config/czce_products.json` | 26 个郑商所品种的乘数、最小变动价位、手续费、保证金、主力合约、换月提醒 |
| `market_data.py` 行情 | 新浪日线 | `data/cache/*.csv` + 质量报告 | 2005 年至今日线；能识别并剔除脏 bar；断网退回缓存并告警 |
| `indicators.py` 指标 | 行情表 | 特征表 | 全部滚动窗口，无前视偏差；状态机可验证 |
| `strategy.py` 信号 | 特征表 | 逐日仓位状态 + 成交事件 + 挂单价位 | 收盘决策、次日开盘成交、盘中挂止损 |
| `risk.py` 风控 | 权益、ATR | 手数、风险倍数 | 单笔风险定额 + 保证金上限 + 回撤守门（不锁死） |
| `backtest.py` 回测 | 信号 + 风控 | 净值曲线、成交明细、指标 | 含 1.5 倍手续费与滑点，输出最大回撤、夏普、活跃度 |
| `scoremodel.py` 赛制评分 | 回测指标 | 三档分项 + 加权总分 | 所有归一化参数可调，能做敏感性分析 |
| `daily_plan.py` 每日计划 | 行情 + 账簿 | `REPORTS/daily/YYYY-MM-DD.md` | 含挂单价、手数、止损、执行时刻表、复盘模板 |

### Should（应做）

- 用 30 分钟数据做日内补充模块（提高活跃度，且只在平今免收手续费的品种上做）。
- 结果 HTML 看板（面试展示用），替代纯 Markdown。
- 每日计划与账簿的自动对账（今天计划 vs 实际成交）。

### Won't（不做，且说明为什么）

| 不做 | 原因 |
|---|---|
| 自动下单 / 接交易 API | 比赛没有公开 API；程序化下单可能违规。红线。 |
| 机器学习预测价格 | 8 周工期 + 数据只有日线，做不出可信的样本外结果，反而会写出无法解释的东西。 |
| 用 vnpy / backtrader / qlib | 用户要能读懂全部代码；引入框架会掩盖逻辑，也超出时间预算。 |
| 实时行情推送 / 数据库 / Web 服务 | 个人本地运行，一条命令跑完即可；加这些只会增加故障面。 |
| 期权策略 | 赛制允许，但期权定价与风控复杂度远超剩余时间，MVP 不碰。 |

## 4. 数据源与更新频率

| 数据 | 来源 | 频率 | 风险 |
|---|---|---|---|
| 日线历史（2005 年起） | AkShare `futures_zh_daily_sina` | 每个交易日收盘后手动刷新 | 新浪连续合约**换月处有跳空**；节假日有重复填充 bar（已自动剔除） |

## 5. 关键假设（必须显式列出）

1. 手续费按**交易所标准 1.5 倍**收取 —— 来自用户提供的赛制说明，未从官方文件核实。
2. 评分权重为**收益率 80% + 回撤 10% + 活跃度 10%** —— 同上。
3. 三部分的**归一化公式未知** —— `scoremodel.py` 全部参数化并提供敏感性分析。
4. 初始虚拟保证金 **50 万元**。
5. 「交割月前一交易日停止交易」为硬约束 —— `contracts.roll_warnings()` 据此给出换月提醒。
6. 夜盘属于**下一个交易日**；郑商所夜盘时间 21:00–23:00。

## 6. 非目标

- 不承诺任何收益率，不回测结果外推到未来。
- 不替代用户对赛制规则的核验。
- 不构成投资建议；本项目只服务比赛用虚拟账户。
